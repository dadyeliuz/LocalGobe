# LocalGobe 0.1.0 Preview 2

גרסת Preview 2 של LocalGobe מבססת את תשתית העדכונים המקוונים (OTA) ומערך ההתקנה והתיקון החכם ב-Windows.

## מה חדש בגרסה זו

- **תשתית עדכונים מקוונים (GitHub OTA Updates)**: החל מגרסה זו (Preview 2), LocalGobe בודקת באופן שקט אם קיימים עדכונים חדשים ומאפשרת בדיקה, הורדה והפעלה מחדש לצורך עדכון ישירות ממסך ההגדרות.
- **התקנה ותיקון חכמים (Smart Setup / Repair)**: קובץ ההתקנה של Windows (`LocalGobe-Setup-0.1.0-preview.2.exe`) מזהה התקנות קיימות:
  - התקנה ראשונה — התקנה נקייה רגילה.
  - גרסה ישנה מותקנת — עדכון במקום (In-Place Update) ללא צורך בהסרה ידנית.
  - אותה גרסה מותקנת — אפשרות לתיקון ההתקנה (Repair) ושחזור קובצי סביבת ההרצה.
  - גרסה חדשה יותר מותקנת — חסימת שדרוג לאחור (Downgrade Protection).
- **סגירה בטוחה במהלך התקנה**: זיהוי אפליקציה פתוחה עם הודעה ידידותית בעברית וסגירה מסודרת של שרתי המשחק למניעת שיבוש נתונים.
- **בידוד מלא של נתוני משתמש**: נתוני המשתמש, החשבונות והקבצים המיובאים ב-`%LOCALAPPDATA%\LocalGobe\data` מבודדים לחלוטין מתיקיית התוכנה ואינם נפגעים בעת עדכון, תיקון או הסרה.
- **ניקיון שורשי מלא של המאגר הציבורי**: מקור המאגר הציבורי וההיסטוריה אופסו ועברו אימות קפדני של טוהר קוד (0 בינאריים של מוגובי, 0 טקסטים מועתקים, 0 תוכן סינתטי).

## שדרוג מ-Preview 1

גרסת Preview 1 קדמה למנגנון ה-OTA ולכן אינה כוללת עדכון אוטומטי.
משתמשי Preview 1 נדרשים להוריד ולהפעיל את `LocalGobe-Setup-0.1.0-preview.2.exe` פעם אחת ידנית:
1. הפעילו את קובץ ההתקנה של Preview 2.
2. ההתקנה תזהה את Preview 1 ותציע עדכון במקום.
3. כל נתוני המשתמש והקבצים המיובאים יישמרו במלואם.
4. מגרסה זו ואילך, עדכונים עתידיים יתקבלו ישירות דרך האפליקציה (OTA).
