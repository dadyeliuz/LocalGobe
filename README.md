# LocalGobe

סביבת הרצה ומעטפת תאימות מקומית עבור עותקים שמורים ונתמכים של מוגובי.

> **קבצי המשחק המקוריים של מוגובי אינם כלולים.**
> LocalGobe אינה מפיצה או כוללת קובצי משחק מוגנים בזכויות יוצרים, כגון חבילות APK, קובצי SWF, חדרים, פריטים, גרפיקה מקורית או מוזיקה. המשתמשים מספקים את הקבצים המקוריים שברשותם, ו-LocalGobe מזהה, מארגנת ומפעילה אותם מקומית מבלי לשנות את הבינאריים המקוריים.
>
> LocalGobe היא פרויקט שימור עצמאי ואינה קשורה, ממומנת או נתמכת על ידי המפעילים או בעלי הזכויות המקוריים של מוגובי.

## הורדה

הדרך המומלצת למשתמש רגיל היא להוריד את קובץ ההתקנה האחרון מעמוד [Releases](https://github.com/dadyeliuz/LocalGobe/releases).

אין צורך ב-Node.js, npm או כלי פיתוח.

1. הורידו את `LocalGobe-Setup-0.1.0-preview.2.exe`.
2. הפעילו את קובץ ההתקנה (התקנה למשתמש הנוכחי, ללא צורך בהרשאות מנהל).
3. פתחו את LocalGobe והוסיפו את קובצי המשחק שברשותכם.

## מצב הפרויקט

LocalGobe נמצאת כרגע בגרסת Preview 2 (`0.1.0-preview.2`).
החל מגרסה זו, נתמכים עדכונים מקוונים (OTA) מתוך מסך ההגדרות של האפליקציה.

התמיכה מתמקדת כרגע ב-Mogobe Android 1.4.7.
חלק מהתכונות והנכסים ההיסטוריים עדיין אינם נתמכים או טרם אומתו ידנית במלואם.

LocalGobe אינה כוללת קובצי Mogobe מקוריים.

למטריצת תמיכה מפורטת ומדויקת ראו את הקובץ [`docs/STATUS.md`](docs/STATUS.md).

## גרסה נתמכת

- **מוגובי אנדרואיד 1.4.7** (`20160725-android-1.4.7`, מקור APK)

ארכיטקטורת המערכת מתוכננת לאפשר תמיכה בעתיד בחבילות APK נוספות ובגרסאות דפדפן היסטוריות.

## תהליך ההפעלה באפליקציה

1. **פתיחת LocalGobe**: פתחו את האפליקציה שהותקנה במחשבכם (או הרצה מקומית ממקור).
2. **הוספת APK של מוגובי**: לחצו על **הוספת מוגובי (APK)** (או גררו ושחררו לחלון את קובץ ה-APK המקורי של מוגובי אנדרואיד 1.4.7). LocalGobe מאמתת את החבילה ומחלצת אך ורק את קובצי המשחק הנדרשים לתוך התיקייה המקומית.
3. **הוספת קבצים מקוריים**: לחצו על **הוספת קבצים מקוריים** (או גררו ושחררו קבצים ותיקיות). המערכת ממיינת ומסווגת את הקבצים באופן אוטומטי לחמש קטגוריות:
   - **משחק (Game)** — קובצי הליבה שחולצו מה-APK.
   - **ממשק (Interface)** — רכיבי ממשק חיצוניים, אפקטים ותכונות משלימות.
   - **עולם (World)** — חדרים ומוזיקת חדרים (קובצי **חדר 20** — SWF ו-TXT — נדרשים לכניסה לעולם; חדרים נוספים מתווספים באופן מצטבר).
   - **פריטים (Items)** — גרפיקת פריטים מכל המשפחות והסוגים.
   - **מיני-משחקים (Mini Games)** — קובצי משחקונים והגדרות מקוריות.
4. ברגע שקובצי **המשחק**, קובצי **הממשק** הנדרשים ו-**חדר 20** זוהו במערכת, כפתור **כניסה לעולם (Play)** ייפתח ויהיה מוכן להפעלה.

## פיתוח ובנייה ממקור (למפתחים)

דרישות קדם: Node.js 22 ומעלה (מומלץ Node 24).

```bash
npm install
npm run dev
```

פקודות נוספות:

```bash
npm run build         # בדיקת טיפוסים (Type-check) ובניית ה-Frontend וה-Desktop
npm test              # הרצת בדיקות יחידה ואינטגרציה אוטומטיות
npm run smoke-test    # בדיקת עשן מהירה ללא ממשק עבור מעטפת ה-Electron
npm run audit:public  # אימות שאין קבצים מוגנים בזכויות יוצרים או דליפות מחקר במקור
npm run audit:release # אימות קפדני של תוצרי ההפצה וההתקנה לפני פרסום
npm run package:win   # יצירת קובץ התקנה מלא (NSIS) עבור Windows 64-bit (x64 / ARM64)
```
